Products worth a look from GitHub Universe 2026

Filed by @thehcma · Oct 29, 2026

A few things from the expo floor worth keeping an eye on. More to come as I dig in.

StepSecurity

CI/CD pipeline security for GitHub Actions - network egress control and runtime security for Actions runners, plus hardened drop-in replacements for risky third-party actions. Relevant to our own Actions hardening/SHA-pinning work.

Tailscale

Zero-config, identity-based mesh VPN (built on WireGuard). Worth a look anywhere we're wiring up private network access between agents, runners, or internal services without standing up a full VPN concentrator.

GitProtect.io

Backup and disaster recovery specifically for GitHub (repos, metadata, LFS) - point-in-time restore to the original account, a new org, another Git host, or local. Relevant given we don't currently have an explicit DR story for brk-tech-labs/brk-commons/brk-oss beyond GitHub's own durability.
